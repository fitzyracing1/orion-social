# Orion social

> **Status:** Spec only. Data model described in chat; no code here.

A social layer for the Orion agent. It keeps contact profiles (relationship, birthday, last contact, interests, check-in cadence), flags overdue check-ins and upcoming birthdays, and drafts messages. It has no send feature; a person sends.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Orion bot, Oct 22 2026) and was not taken further at the time. This repo records it so it can be picked up later.
